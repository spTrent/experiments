# Признаки для восьми горизонтов

Для каждого маршрута старт прогноза cutoff сдвигается на 30 минут. Время цели t = cutoff + h × 30 минут. Признаки используют только факты до cutoff включительно. Для подбора, локального test и сабмита старт фиксируется в 10:30.

## Обучающие строки и файлы

Ноутбук feature_engineering.ipynb читает train_solo_track.parquet и test_solo_track.parquet из data. На Kaggle он также ищет пару файлов внутри /kaggle/input. Результаты сохраняются в artifacts/features относительно рабочей папки.

Каждой модели соответствует пара history_hN.parquet и submission_hN.parquet. В обоих файлах строка содержит маршрут, дату начала прогноза cutoff, время цели timestamp и признаки. История дополнительно содержит y (значение target_1h в момент t), тест — исходный id. Для обучения исключают cutoff, timestamp, y и id. Целочисленный route_id передают CatBoost как категориальный признак.

История начинается с первого получаса. Неизвестные лаги остаются NaN, окна и сезонные средние используют доступные значения. Для каждого h сохраняются все строки с известной меткой именно этого горизонта. Данные пишутся блоками до 48 стартов. При проверке в train входят только строки с меткой до начала первого дня подбора. Перед сабмитом каждая модель переобучается на всей размеченной истории.

## Словарь признаков

| Колонки | Расчёт |
|---|---|
| route_id | Категория маршрута. Остальные исторические признаки вычисляются отдельно по этому маршруту. |
| weekday_sin, weekday_cos | Синус и косинус угла 2πd/7, где d = 0 для понедельника, …, 6 для воскресенья. День берётся от t. |
| half_hour_sin, half_hour_cos | Номер получаса дня s от 1 (00:00) до 48 (23:30). Угол 2π(s−1)/48. В train меняется вместе с временем старта. |
| target_back_0, 1, 2, 4 | Последнее значение target_1h и значения на 1, 2, 4 получасовых шага раньше cutoff. |
| target_1h_mean_4, target_1h_mean_12 | Средние по последним 4 и 12 наблюдениям, включая cutoff. Это средние часовых объёмов с перекрывающимися окнами. |
| target_vs_mean_6h | Последний target_1h минус его среднее по 12 точкам. |
| slot_days_back_1, 2, 7 | Значение таргета в тот же получасовой слот, что и t, за 1, 2 и 7 дней до него. |
| slot_daily7, slot_weekly4 | Среднее таргета в слот t за 7 предыдущих дней и отдельно за 4 предыдущих таких же дня недели. Полусумма колонок даёт сезонный прогноз для сравнения. |
| status_i_latest, status_i_mean_4, status_i_mean_12, status_i_change_1h | Для каждого из шести статусов: значение в cutoff, средние по последним 4 и 12 точкам, значение в cutoff минус значение час назад. |
| morning_level_ratio | Среднее последних четырёх точек до cutoff включительно, делённое на среднее за те же слоты предыдущих семи дней. При нулевом знаменателе — NaN. |

Для сабмита объединяют прогнозы всех восьми горизонтов по id. Для локальной оценки собирают восемь горизонтов одного дня и считают WAPE + |Relative Bias| по всем маршрутам и слотам вместе.
