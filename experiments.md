## Идеи для оценки пользователем, 8 ноября

Обсуждение, реализация не согласована. Проверки корреляций выполнены на истории до 4 октября, без обучения моделей. Каждый ряд делился на собственное среднее, затем корреляции считались по объединённым наблюдениям.

- Масштабированный MAE на всех восьми горизонтах как исправление текущего контроля. Дополнительно проверить фактический leaf_estimation_method в Kaggle и поддержку Exact установленной версией. Пока scaled реализован только для h=2.
- Прогноз поправки к сезонному уровню. Базовый прогноз строить отдельно для каждого исторического старта только из прошлого.
- Цепочки обработки: лаги каждого статуса, изменения и отклонения от обычного уровня маршрута/слота. status_3 имеет корреляцию с будущим нормализованным таргетом около 0,418 на h=1 и 0,009 на h=4; status_2 — 0,251 на h=2. Это описательные связи, не доказательство выигрыша.
- Динамическая общая нагрузка: агрегаты таргета и статусов по маршрутам до cutoff, их отклонения от обычного уровня. Опционально отдельный прогноз общего объёма и проверяемое согласование индивидуальных прогнозов с суммой.
- Длина окна и вес недавней истории: 14/28/56 дней против всей истории. Проверка будущих стартов только из 10:30, с одинаковыми датами сравнения.
- Профили соседних исторических слотов: t ± 30/60 минут вчера/неделю назад, диапазоны пиков, гармоники суточного профиля. Будущие слоты текущего дня недоступны.
- Режим смеси по горизонту и широким группам маршрутов с разной долей нулей и вариативностью. Общий вес как контроль, веса групп стягивать к нему.
- Сравнение MAE с RMSE либо Quantile на небольшом диапазоне alpha выше 0,5, подбор по полной конкурсной метрике. MAE оценивает медиану, штраф за общий объём может предпочесть другой баланс. Дополнительный вес крупных маршрутов при MAE без нормализации не вводить автоматически.

Проверка каждой идеи на нескольких последовательных временных окнах. Уже просмотренные последние 14 дат больше не считать нетронутым тестом для новых решений.
