# Отдельные rich-эксперименты

Запускать самостоятельно в Kaggle с подключённым `case_rwb` и включённым GPU:

- `catboost_rich_calibration.ipynb` — CatBoost MAE, параметры rich-конфигурации с WAPE 0.31815. Параметры каждого горизонта взяты из `artifacts/catboost_direct/model_params`, с ограничениями глубины6 и900 деревьев именно из того rich-запуска.
- `xgboost_rich_calibration.ipynb` — XGBoost MAE, точные `refit_params` из `notebooks/xgb_tuning/best_params/best_h1.json` … `best_h8.json`. Выбранные числа деревьев сохранены без дополнительных ограничений.

216 расширенных признаков плюс категориальный маршрут. Восемь горизонтов, общая модель и8 кластеров. Базы обучаются на всех получасах. Нормировка по маршрутам и набор признаков отличаются от исходного XGB tuning: перенос параметров не воспроизводит автоматически его метрики.

Val14дней делится на7дней обучения калибровок и7дней выбора. После выбора коэффициенты переоцениваются на всём val и замораживаются до test14дней. Группы калибровки фиксируются до val. Все способы сравниваются на test только для отчётности, победитель остаётся выбранным по val.

18 способов: без коррекции; заданные множители1.025/1.05; общий обученный множитель; горизонтные, групповые, группа×горизонт, со сглаживанием50% и без; множители с давностью2/3/7дней; аддитивный сдвиг; affine общая, по горизонту, по группе и групповая со сглаживанием. Affine минимизирует WAPE + |Relative Bias|, наклон ограничен0.5…1.5, результат ограничивается снизу нулём. Малые группы используют глобальный fallback. Rolling-обновления по меткам test не используются.

`all_calibrations_train_test.csv` содержит train/test для всех методов. Сохраняются также коэффициенты, происхождение параметров, прогнозы OOF, модели и ZIP. Перед raw/calibrated submission выбранные модели и обучаемые статистики полностью переобучаются на всей размеченной истории. Финальные коэффициенты обновляются на доступных OOF val/test без повторного выбора способа. Независимая от полного refit оценка test получена до этого переобучения. Сам test уже использовался в прежних исследованиях.

Ночного лимита времени нет. CPU fallback обучения запрещён. Эти ноутбуки подготовлены и проверены синтетически; настоящее GPU-обучение при подготовке не выполнялось.

Генератор: `scripts/build_rich_calibration_notebooks.py`. Проверка: `scripts/check_rich_calibration_notebooks.py`.
