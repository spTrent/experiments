# Чекпоинт с Public score 0.328

Откройте соседний reproduce_best_checkpoint_0328.ipynb в Python 3.14 и выполните Run All.
GPU для восстановления не нужен. Существующее ядро experiments/.venv подходит.
При переносе сохраните рядом с ноутбуком эту папку.

В комплекте: исходные train/test, восемь базовых CatBoost-моделей, две оценочные и две
финальные модели поправки, исходный код признаков и поправки, OOS-кэш, словарь лагов,
эталонный submission и метрики. Все веса в CBM; pickle не требуется.

По умолчанию признаки и базовые прогнозы строятся заново из raw train, затем восстанавливается
submission. Валидация воспроизводится по сохранённому OOS-кэшу базовых моделей.
REFIT_CALIBRATORS=True переобучает только модели поправки. Полное обучение восьми базовых
моделей этот ноутбук не запускает.

Public 0.328 сообщён пользователем 10 ноября 2026. Локальный pooled score 0.321453823624,
средний дневной 0.338300892826. Это разные виды оценки; цель Public <0.322 ещё не достигнута.

Исходная среда сервера указана в environment.json и requirements-reproduce.txt.
Устанавливать пакеты автоматически ноутбук не будет.

Комплект очищен от дублирующего ZIP, ненужных отчётов, train_range.json и копии test-ключей.
Рабочие файлы экспериментов сохранены отдельно в stepa_work_archive_20261110.
