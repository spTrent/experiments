# Session6

Откройте `session6.ipynb` и выполняйте ячейки сверху вниз. В checkout веса и код находятся в `best/`, а ссылки из `best/data/` ведут к исходным parquet в корневом `data/`. При переносе только папки `best/` скопируйте сами parquet по этим ссылкам. Для восстановления достаточно CPU.

Результат на закрытом тесте соревнования **0,326**, по сообщению команды. Локальная WAPE + |Rbias|: **0.319190199953**. 

Готовый отправленный CSV: `submission_session6.csv`. Новый расчёт сохраняется в `outputs/submission_session6_reproduced.csv`.

Выберите Python-окружение с зависимостями комплекта. Список исходных серверных зависимостей — `bundle/requirements-reproduce.txt`. Автоматическая установка не выполняется.

Структура:
- `session6.ipynb` — метрики и восстановление прогноза;
- `data/` — неизменённые train/test parquet;
- `bundle/` — восемь LightGBM-моделей, код признаков, метаданные и исходный прогноз 0328;
- `validation_predictions.parquet` — сохранённые OOS-прогнозы 18–31 октября;
- `input_hashes.json` — контроль входных файлов;
- `package_verification.json` — проверка переноса и повторного расчёта.

Полное обучение исходных моделей не запускается. Ноутбук проверен структурно и синтаксически; критический путь восстановления прогноза проверяется отдельным CPU-запуском. Полный ноутбук автоматически не исполнялся.

В Session6 исходные модели повторно не обучались, в манифесте указано `source_models_refitted=false`. Локальная оценка получена до финального переобучения. Для нового сабмита требуется переобучение на всей доступной размеченной истории.
